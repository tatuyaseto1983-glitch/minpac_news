# 調査レポートの置き場

このフォルダに **HTMLファイルをそのまま置くだけ** で、サイトの「レポート」に載ります。
中身は書き換えません。作ったときの見た目のまま公開されます。

```
content/reports/
  群馬県民泊分析レポート.html      ← これを置くだけ
  群馬県民泊分析レポート.pdf       ← 同じ名前でPDFを置くと「PDF版」のリンクが付く
  群馬県民泊分析レポート.json      ← 任意。表題や要約を自分で決めたいときだけ
  _private/                        ← ここに入れたものは公開されません
```

## 自動で読み取るもの

| 項目 | どこから |
| --- | --- |
| 表題 | HTMLの `<title>` |
| 要約 | HTMLの `<meta name="description">` |
| 日付 | ファイル名の先頭の `2026-09-07-`。無ければファイルの更新日 |
| 対象エリア | 本文に出てくる都道府県名 |

## 自分で決めたいとき（任意）

同じ名前で `.json` を置くと、そちらが優先されます。

```json
{
  "title": "群馬県 民泊エリア分析レポート",
  "summary": "草津・伊香保・水上の3エリアを、宿泊需要と競合の観点から比較しました。",
  "kind": "エリア分析",
  "date": "2026-09-07",
  "areas": ["群馬県"]
}
```

`kind` はレポートの種類の表示名です（例：エリア分析／エリア診断／市場調査）。

## 公開したくないレポート

このサイトは誰でも見られます。お客さま名や物件の住所が入っているものは、
`_private/` に入れてください。公開もされず、Gitにも記録されません。
