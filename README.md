# 民泊コンパス（仮）

民泊・簡易宿所・旅館業法に関する情報を、行政の一次情報と信頼できる報道からまとめるニュースサイトの企画リポジトリです。

## 中身

| ファイル | 内容 |
| --- | --- |
| [docs/01_要件定義書.md](docs/01_要件定義書.md) | 目的、対象読者、機能、データ設計、技術構成、体制、費用、リスク、KPI |
| [docs/02_情報ソース仕様.md](docs/02_情報ソース仕様.md) | 収集する行政データ・報道の一覧と、取得から公開までの処理の流れ |
| [ui/screen-design.html](ui/screen-design.html) | 画面設計案（6画面）。ブラウザで開いてご覧ください |

## 進め方

1. 要件定義書の第15章「次に決めていただきたいこと」を確定
2. 画面設計案へのフィードバックを反映
3. 詳細設計・見積もり → 開発
