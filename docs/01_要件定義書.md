# 民泊コンパス 要件定義（実装版）

民泊・簡易宿所・旅館業法のニュースを、行政の一次情報から自動で集めて公開する静的サイトです。
このファイルは「何を作ったか」「どこを直せばいいか」をまとめたものです。

---

## 1. 何をするアプリか

**観光庁の発表を毎日自動でチェックして、民泊に関わるものだけを抜き出して並べるサイト**です。

- サーバーは使いません。GitHub Actions が1日1回動いて、HTML を作り直します。
- 外部ライブラリはゼロ。Node.js だけで動きます。
- 費用はかかりません（GitHub Pages と Actions の無料枠で完結します）。

例えるなら、新聞を全部読んで民泊の記事だけ切り抜いてくれる係を、毎朝5時に自動で動かしているようなものです。

## 2. 誰のためのものか

| 対象 | 使い方 |
| --- | --- |
| これから民泊を始める人 | 制度の変更を見落とさない。解説記事で全体像をつかむ |
| すでに運営している人 | 施行状況の更新、システムの告知、宿泊税などの変更を追う |
| 支援する立場の人（工務店・不動産・士業） | 顧客に説明する材料として、出典付きで使う |

## 3. 画面

| URL | 内容 |
| --- | --- |
| `/` | ホーム。ニュース一覧ではなく、検索・注目ニュース・数字・エリア・テーマ・開業ガイドをまとめたダッシュボード |
| `/news/` | ニュース。注目ニュースと新着、右にキーワード検索・エリア・テーマ・情報の種類・注目キーワード、下にページ送り |
| `/area/` `/area/<都道府県>.html` | エリア別。47都道府県ぶん。制度ごとの可否（手入力）＋その地域のニュース |
| `/stats/` | データ。宿泊の受け皿の比較、届出の生存率、話題のエリア／テーマ別本数、これから足したい数字 |
| `/laws/` | 法令・条例。民泊に関係する6つの法律を「何を決めているか」から引ける形に。厚労省の主な通知・資料も掲載 |
| `/start/` | 民泊を始める。開業までの7ステップと、各ステップで確認すること |
| `/guides/` `/guides/<slug>.html` | 解説記事 |
| `/about.html` | 情報源、情報の扱い方、免責事項（ヘッダーから外し、フッターに配置） |

ヘッダーは **ニュース／エリア／データ／法令・条例／解説** の5つと検索に絞り、スクロールすると高さが縮む固定ヘッダーにしています。

## 5. 取り込みの判定

`data/keywords.json` の `tiers` で、記事の重要度を3段階に分けています。

| tier | 意味 | 例 |
| --- | --- | --- |
| 3 | 民泊・宿泊制度そのもの | 民泊、住宅宿泊事業、簡易宿所、特区民泊、旅館業、宿泊税 |
| 2 | 宿泊の統計まわり | 宿泊旅行統計、客室稼働率、延べ宿泊 |
| 1 | 観光まわりの周辺情報 | インバウンド、訪日外国人、空き家 |

tier 1・2 は `exclude` に当たる語（入札、人事異動など）が入っていると取り込みません。
tier 3 は除外しません（制度の話は取りこぼしたくないため）。

カテゴリ・エリア・事業形態も同じファイルのルールで自動判定します。**ルールを直して `npm run fetch` を実行すると、すでに保存済みの記事にも分類が付け直されます。**

## 6. データの持ち方

```
data/
  sources.json    取得先の定義（手で編集）
  keywords.json   取り込み・分類のルール（手で編集）
  areas.json      自治体ごとのルール（手で編集）
  articles.json   収集結果（自動生成・Gitで履歴が残る）
  stats.json      届出件数と、その履歴（自動生成）
  documents.json  旅館業法まわりの法令・通知・資料（自動生成）
```

記事1件に持たせている項目：

| 項目 | 用途 |
| --- | --- |
| `title` / `url` / `publishedAt` | 表示と並び順 |
| `sourceId` / `sourceName` / `isPrimary` | 出典表示、「一次情報」ラベル |
| `category` / `areas` / `businessTypes` | 絞り込み |
| `score` | 1〜3。トップページの並べ分けに使う |
| `fetchedAt` / `lastSeenAt` | 取得ログ。消えた記事の判定にも使う |

同じURLでも見出しが違えば別の告知として扱います（施行状況の更新など、同じページを指す告知が繰り返されるため）。
逆に、取得できた期間の中にあるのに今回見つからなかったものは、削除・修正されたとみなして消します。

## 7. 守っていること（重要）

| 項目 | 実装 |
| --- | --- |
| 著作権 | 記事本文は保存も表示もしない。見出し・公開日・発表元・リンクのみ |
| アクセス負荷 | 同一プロセスからの連続アクセスは1.5秒以上あける。取得は1日1回 |
| 出典 | 数字には必ず出典リンクと取得日を添える |
| 免責 | 全ページのフッターに「最終判断は管轄窓口へ」を常設 |
| 誤りの可能性 | 自動分類のため誤りが混じることを `/about.html` に明記 |

## 8. 厚生労働省まわりの扱い

厚労省からは、性質の違う2つを取っています。

| 取得先 | 性質 | 出し先 |
| --- | --- | --- |
| 新着情報 RSS | ニュース（旅館業の話が出るのは月に数回あるかどうか） | ニュース一覧 |
| 旅館業のページ | ニュースではなく**資料集**。法令・通知・パンフレット | `/docs/` の一覧 |

資料集のほうは頻繁には変わりませんが、「簡易宿所の許可取得の手引き」「旅館業法のFAQ」「玄関帳場の効率化事例集」など、開業実務でそのまま使えるものが並んでいます。**日付が書かれているものは和暦を西暦に直して並べています**（41件中14件に日付あり）。

## 9. 数字のページ

| 見出し | 中身 | 出どころ |
| --- | --- | --- |
| 宿泊の受け皿はどれくらいあるか | 旅館・ホテル／住宅宿泊事業（現存）／簡易宿所 の3本を横棒で比較 | 民泊制度ポータル＋厚労省 |
| 届出のうち、およそ3件に1件はやめている | 累計届出に対する現存と廃止の割合 | 民泊制度ポータル |
| いまの登録数 | 届出・廃止・現存・管理業・仲介業 | 民泊制度ポータル |
| 届出件数の推移 | 時点が2件以上たまると表示 | 民泊制度ポータル（履歴） |
| いま話題になっている場所 | 直近90日の記事本数を都道府県別に | このサイトが集めた記事 |
| 何が話題になっているか | 直近90日の記事本数をカテゴリ別に | このサイトが集めた記事 |

**グラフのつくり方の決めごと**

- 色は2色だけ。ティール＝住宅宿泊事業法（民泊）、アンバー＝旅館業法。意味に紐づけています。
- **値は必ず棒の横に直接書きます。** 色が見分けにくい環境でも読めるようにするためです。配色は色覚の違いを考慮した検証を通しています（ライト・ダークの両方）。
- 外部のグラフライブラリは使わず、HTMLとCSSで描いています。
- **時点が違う数字を並べるときは、その旨を必ず添えます**（住宅宿泊事業は令和8年7月15日、旅館業は令和6年3月末）。
- このサイトが集めた記事の本数は「施設の数ではない」と明記します。集め方の都合で古い時期ほど取りこぼすため、**月ごとの推移は出していません。**

## 10. 表示のつくり

### 同じ話題をまとめる

報道は同じ出来事を何社も報じます（新宿区の条例改正では14件）。見出しの文字の重なり具合（2文字ずつの一致率）と日付の近さで1つの話題にまとめ、代表の1件だけを出して「ほか◯媒体」と添えています。代表は、集めた記事の中で掲載本数の多い媒体を優先します（媒体の格付けは持っていません）。

## 9. デザインの決めごと

### 文字

| 用途 | 指定 |
| --- | --- |
| 日本語 | Zen Kaku Gothic New |
| 英数字・日付・数値 | Inter（`font-family` の先頭に置き、日本語は自動で Zen Kaku に落ちる） |
| 見出し・記事タイトル | 600〜700 |
| 本文 | 400 |
| 補助情報 | 400〜500 |

サイズは **タイトル17〜30px ／ 本文14〜15px ／ 補助11〜12px** の3段。字間はタイトルで −0.015〜−0.03em に詰め、日本語が間延びしないようにしています。数字には `tabular-nums` を当てて桁をそろえます。

### 面と色

- 背景は白〜ごく薄いグレー（`#F7F9F8`／`#FFFFFF`）。
- 主色は深いグリーン。アンバーは開業・補助金まわりのアクセントだけに使います。
- **枠線をほぼ使わず**、余白・文字サイズ・背景色・影で階層をつくります。カードは細い影のみ。
- 角丸は 6px（小さい要素は 4px、ピルは全丸）。
- コンテンツ最大幅は 1200px。

### タグとラベル

役割で見た目を分けています。

| | 見た目 |
| --- | --- |
| カテゴリ（6種） | 色つきの点＋文字。色面は使わない |
| エリア | 枠線のピル |
| 一次情報 | 薄いグリーンのピル |

### 民泊事業者への影響

各記事に必ず1つ付く独自情報です。**記事の中身の要約ではありません。** 見出しに出てくる動き（原則禁止／受付停止／規制強化／緩和／改正／取締／トラブル／補助／検討／急増）と、こちらで付けた分類・地域から、「読んだ人が次に何を確認すればよいか」を組み立てています。地名は市区町村が見出しにあればそちらを優先します。

薄いグリーンの面に載せて、記事本文の要約（AI要約・一言メモ）とは見た目で区別しています。

## 11. まだできていないこと

| 項目 | 状況 |
| --- | --- |
| 自治体ごとの制度別の可否 | 窓口・条例の有無は自動で入るようになった。「住宅宿泊事業はできるか」などの可否は `data/areas.json` に手で入れる |
| e-Stat API（宿泊旅行統計の数値） | 未接続。無料の利用登録（appId）が必要 |
| 都道府県別の届出件数 | 出典がPDFのみ。この環境ではPDFを読めないため未取得 |
| 全文検索 | 現状はニュース一覧でのタイトル部分一致のみ |
| 解説記事 | 1本のみ（`content/articles/`） |

## 12. 直すときの入口

| やりたいこと | 触るファイル |
| --- | --- |
| 取得先を足す／消す | `data/sources.json`（新しい形式なら `scripts/lib/parse.mjs` にパーサを追加） |
| 拾う記事を増やす／減らす | `data/keywords.json` |
| 自治体のルールを入れる | `data/areas.json` |
| 解説記事を書く | `content/articles/*.md` |
| 見た目を変える | `scripts/lib/theme.mjs`（色とカードのCSS） |
| グラフを足す | `scripts/lib/charts.mjs` |
| 一言メモを足す | `data/blurbs.json` |
| 話題のまとめ方を変える | `scripts/lib/cards.mjs` の `clusterNews`（しきい値0.35） |
| 「影響」の言い回しを変える | `scripts/lib/cards.mjs` の `SIGNALS` と `IMPACT` |
| 画面の構成を変える | `scripts/build.mjs` |
